# AI 에이전트 workflow

## 세션 시작 순서

1. `ai-workflow/memory/active/state.json`
2. `ai-workflow/memory/active/session_handoff.md`
3. `ai-workflow/memory/active/backlog/` 최신 항목
4. `docs/PROJECT_PROFILE.md`
5. 이 wiki index와 필요한 canonical 문서

## 작업 원칙

- 목적·범위·영향 문서를 먼저 정리합니다.
- 상태는 `planned`, `in_progress`, `blocked`, `done` 중 하나로 관리합니다.
- 검증하지 않은 결과를 완료로 기록하지 않습니다.
- 사용자 보고와 workflow 문서는 기본적으로 한국어로 작성합니다.
- 세션 종료 전 state, handoff, 최신 backlog의 current focus를 정합시킵니다.
