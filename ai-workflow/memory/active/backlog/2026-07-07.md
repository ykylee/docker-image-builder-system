### 1.3 사전 결함 + 보강 2건

- **macOS `security` 비대화형 환경 한계** — Mavis 의 bash tool 환경 (non-interactive zsh) 에서 `security add-generic-password` 호출 시 entry 가 등록된 듯한 rc=0 이지만 실제로는 entry 미등록. 사용자가 interactive zsh 에서 `-A` (always allow) 옵션으로 직접 추가해야 동작. 비대화형 read 도 keychain 이 unlocked 상태일 때만 동작 (perl alarm timeout 내 read). 회피: helper 가 매번 `perl alarm 8` + `head -c 200` 으로 read + 즉시 사용 (cache ❌).
- **`python3 - <<HEREDOC` pipe stdin hijack** — `_caldav__report_vtodos | _caldav__todos_to_json` 호출 시 `python3 - <<'PY'` 가 stdin 을 heredoc 로 고정하여 pipe 의 XML data 가 python 에 안 들어감 (`ET.fromstring('')` ParseError). fix: `python3 - "$xml" <<'PYEOF'` (data 를 argv 로 전달) 패턴 — heredoc 는 code, argv 가 data. 동일 패턴을 `cmd_show` 에도 적용.
