### 1.4 사후 결함 + 보강

- svelte-check 가 tsconfig.json 의 `src/**/*.tsx` include 로 React JSX 파싱 시도 → 13 errors. **해결**: tsconfig.json exclude 에 `src/react/**` 추가. React 는 tsconfig.react.json 전용.
- vite alias `@` 를 `/src` (앞 슬래시) 로 설정 시 vitest 가 module resolution 실패. **해결**: path.resolve(__dirname, "src") 절대경로 + vite.config.ts 와 vite.react.config.ts 동일 패턴.
- tsconfig.react.json 의 paths 와 vite alias 가 분리되어 있어 typecheck 와 runtime import 각각 설정 필요. **결정**: 양쪽 모두 동일하게 유지 (single source: tsconfig paths = typescript, vite alias = runtime).
- React 19 의 global `JSX` namespace deprecation. **해결**: `import type { ReactElement } from "react"` + return type ReactElement.
- @testing-library/jest-dom matcher type (`toHaveTextContent` / `toBeInTheDocument`) 가 vitest types 와 정합 안됨. **해결**: tsconfig.react.json `types` 에 `@testing-library/jest-dom` 추가.
- pnpm install ERR_PNPM_IGNORED_BUILDS 정책으로 modules purge 후 install prompt 가 interactive. **해결**: `--config.confirmModulesPurge=false` 옵션으로 non-interactive install.
